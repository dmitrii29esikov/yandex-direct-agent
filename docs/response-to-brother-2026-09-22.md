## 6. Яндекс Тег Менеджер: что на самом деле стоит между заявкой и целью

Контейнер 1007795, всё проверено по API (код тегов и условия триггеров).

**Теги:** `INIT_RSYA_VALIDATOR` (триггер All Pages), `Printyard Main Lead (GOOD RSYA)`
и `Analytics — Заявка (contact-form)` (оба на триггере `4600583` — custom_event
`printyard.form_success`), вебмастер (initialization).

**Что делает INIT_RSYA_VALIDATOR:** читает `utm_source` и сверяет с белым списком
(`yandex, google, mail, vk, dzen, partprice, katalogi-tovarov-ceny, amd.online,
pogoda.yandex, ru.beru.android, top10deals, facebook, instagram`); пустой
`utm_source` тоже считается «хорошим»; чёрный список в коде отключён.
Результат кладёт в `window.is_good_rsya_traffic`.

**Что делает тег лида:** ищет поля формы по placeholder'ам
(`input[placeholder="Анна Иванова"]`, `input[type=email]`,
`textarea[placeholder*="Тип упаковки"]`), ждёт появления в тексте страницы фразы
«Спасибо. Мы получили заявку и свяжемся с вами.», проверяет имя ≥2, корректный
email, текст проекта ≥5 — и только потом:

```js
if (window.is_good_rsya_traffic !== true) { console.log('❌ Плохой трафик'); return; }
ym(106104483, 'reachGoal', 'goal_main_lead');
```

**Выводы:**

1. Цель `568489549` (`goal_main_lead`) вызывается **не из кода сайта, а из тега
   в Тег Менеджере** — обе версии совместимы, вопрос закрыт.
2. Фильтр трафика **не «слишком строгий» для Директа**: `utm_source=yandex`
   проходит, пустой тоже. Но `utm_source='ya'` (13 визитов за период) **не
   проходит** — в списке нет подстроки `yandex`, а `chatgpt.com` (9 визитов)
   не проходит тем более. Заявки из таких визитов в цель не попадут вообще.
3. Риск не в строгости фильтра, а в **цепочке из трёх условий**: сайт прислал
   событие `printyard.form_success` → поля найдены по placeholder'ам и прошли
   валидацию → визит признан «хорошим». Ломается любое звено — цель молчит,
   и теряется не трафик, а **учёт заявок**.
4. Правильный принцип: фильтровать трафик для **оптимизации** (ставки, площадки),
   но не для **учёта** конверсий. Учёт должен быть безусловным, иначе статистика
   врёт в обе стороны.
5. Самая надёжная цель в Директе — стандартная цель Метрики **«отправка формы»
   (`608959488`)**: она не зависит ни от placeholder'ов, ни от фильтра.
   Предложение: сделать её основной денежной целью, а JS-цель `goal_main_lead`
   оставить аналитической (убрав из неё фильтр трафика).
6. Два триггера `form_submission` (`3708768 TR_LEAD_GOOD_RSYA`,
   `3743458 TR_LEAD_GOOD_RSYA_ANALYTICS`) не привязаны ни к одному тегу —
   по названиям это прежняя схема учёта заявки. Либо привязать, либо удалить:
   сейчас они только путают отладку.

все четыре разобраны. Значит он либо в другом контейнере проекта, либо в коде
